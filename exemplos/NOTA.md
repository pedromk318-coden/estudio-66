# Exemplos

Dez reels de referência, todos com o mesmo tema (um foguete decolando), para mostrar como cada motor de estilo foi adaptado para o vertical 1080×1920. Use-os para aprender a técnica; o reel da pessoa tem sempre roteiro, cenas e objetos próprios.

Para ver um exemplo: `cd biblioteca && node core/render/still.mjs "../exemplos/ukiyoe" 3 --size 1080x1920`.

Os arquivos de motor copiados aqui (`print.js`, `px.js`, `ui.js`, `font.js`, `holo.js`, `hud.js`, `chalk.js`, `cel.js`, `fx.js`, `post.js`, `draw.js`, `paper.js`, `toon.js`, `chars.js`, `engine.js`, `glass.js`, `bricks.js`) vêm da biblioteca Lemo-Opuscar da LemoLab (licença MIT, texto em `../biblioteca/LICENSE`); alguns tiveram só as constantes de tamanho trocadas para o vertical.
